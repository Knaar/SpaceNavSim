# SpaceNavSim

Упрощённая симуляция космической навигации на Unreal Engine 5.7 с использованием C++ и Blueprints. Задача аппарата — пройти от стартовой позиции до целевого маркера B через процедурно сгенерированную планетарную систему.

## Требования и запуск

Windows 64-bit. Распакуйте готовую сборку и запустите `SpaceNavSim.exe`.

## Механики и управление

Симуляция включает орбитальное движение небесных тел, гравитацию, тягу двигателя, расход топлива и визуализацию маршрута. По мере расходования топлива уменьшается текущая масса аппарата.

| Клавиша | Действие |
| --- | --- |
| 1 | Построить экономичный маршрут — Fuel Efficient |
| 2 | Построить быстрый маршрут — Time Efficient |
| 3 | Построить сбалансированный маршрут — Balanced |
| 4 | Запустить или остановить полёт |

Экономичный маршрут использует прямые участки и движение по инерции. Быстрый маршрут строится по плавным траекториям. Сбалансированный режим учитывает расход топлива, время и риск с настраиваемыми весами.

Маршрут рассчитывается по актуальному состоянию аппарата и небесных тел. Автопилот выполняет движение по заранее рассчитанным сегментам. Безопасность проверяется перед запуском и во время полёта. После остановки необходимо построить новый маршрут.

## Архитектура

Основная связующая логика находится в `BP_SpaceNavPawn`. Его C++ основа содержит меш корабля, камеру, компонент движения и девять точек размещения двигателей.

На `BeginPlay` Blueprint инициализирует хранилище ресурсов, двигатель, бортовой компьютер, UI, визуализацию двигателей и привязки событий.

| Компонент | Назначение |
| --- | --- |
| `USpaceNavResourceStoreComponent` | Хранение топлива и события его изменения |
| `USpaceNavEngineComponent` | Тяга, повороты, скорость и гравитация |
| `USpaceNavOnboardComputerComponent` | Расчёт массы, скорости и расхода топлива |
| `USpaceNavRouteComponent` | Асинхронный расчёт маршрутов, их визуализация и автопилот |
| `USpaceNavUIComponent` | Создание виджетов, отображение показателей и индикация ввода |
| `USpaceNavThrusterVisualComponent` | Пламя двигателей и освещение |

Граф `Main Work` связывает компоненты через делегаты. В `Movement Graph` девять событий движения соединены с соответствующими действиями двигателя.

Клавиши запускают построение маршрутов и передают индикацию нажатия через UI-компонент и главный виджет в соответствующее событие `OnPressed` навигационного виджета.

`ASpaceNavSystemGenerator` создаёт центральное тело, планеты и маркеры миссии.

## Настройки

Параметры отделены от логики симуляции и задаются через Data Assets:

- `USpaceNavSystemGeneratorDataAsset`: random seed, параметры небесных тел, диапазоны орбит и граница системы.
- `USpaceNavPawnSettingsDataAsset`: стартовое тело и орбита, начальная скорость, масса, топливо и параметры двигателя.
- `USpaceNavRouteOptimizationDataAsset`: веса критериев, параметры поиска и настройки безопасности.

Одинаковые seed и настройки генерации воспроизводят одинаковую начальную конфигурацию системы.
